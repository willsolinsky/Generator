# Review / Retest / Rework

## Purpose
Capture how markup and quantity work gets improved over cycles.

## Cycle structure
### Cycle 0 – Evidence
- gather plans, details, workbook, takeoff examples, Bluebeam tools
- define feature list and authority sheets

### Cycle 1 – Geometry trace
- identify obvious lines and areas
- do not lock quantities yet
- flag uncertain entities

### Cycle 2 – Classification
- assign each entity a class
- compare against legend and standard details

### Cycle 3 – Reconciliation
- compare against workbook totals and takeoff references
- document overages, shortages, and missing items

### Cycle 4 – Rework
- revise geometry
- revise classification rules
- update project dictionary

### Cycle 5 – Final
- export marked sheets
- export overall project summary
- preserve lessons learned

## Error buckets
- missing geometry
- wrong feature class
- wrong authority sheet
- wrong quantity rule

## Required outputs each cycle
- reviewed files
- what changed
- what remains uncertain
- next pass tasks
