# Takeoff System Overview

This repository stores reusable standards, project knowledge, review cycles, parsing logic, and output conventions for construction takeoff markup.

## Inputs
- Civil plan set PDFs
- Marked-up takeoff PDFs
- Quantity workbooks
- Bluebeam toolsets (.btx)

## Outputs
- Feature dictionaries
- Sheet role maps
- Colored overlays
- Quantity reconciliation reports
- Final overall markup summaries

## Operating principle
Geometry first. Classification second. Quantities third. Overview last.
