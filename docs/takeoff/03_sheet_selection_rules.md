# Sheet Selection Rules

## Goal
Select the correct sheet for identifying each feature before markup begins.

## Preferred sources
- GO sheets: overall continuity and drainage context
- P sheets: curb, gutter, sidewalk geometry
- X sheets: section authority for classification
- CD sheets: details for ramps, aprons, inlets, transitions
- PP sheets: profile confirmation

## Rules
1. Never rely on one sheet alone.
2. Use sections to confirm ambiguous linework.
3. Use workbook naming as the source of truth for class names.
4. Use marked-up takeoffs to confirm field conventions.
